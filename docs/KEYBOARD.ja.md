# キーボードとマルチプレイチャット

[English](KEYBOARD.md) | **日本語** · [操作方法](CONTROLS.ja.md)

## 原作メニュー・ロビー・入力欄

自動表示は無効です。原作互換画面、メニュー、または入力欄を持つウィンドウで **BまたはYを1秒長押し**すると表示します。1秒に達した時点で開くので、離す必要はありません。入力先の欄を選んでから入力してください。画面下端の欄ではその上に配置することがあります。入力中は表示位置を維持します。

**Enter**は原作の欄へEnterを送って閉じます。**Close**は追加のキーを送らず閉じます。入力済みの文字を取り消す操作ではありません。下記のVRチャット用とは異なり、2DウィンドウのポインターはOS側の操作に従います。

原作のレベル選択を開くには、入力キーボードで **Shift保持** を有効にし、保持中の案内が出ている間に **New Game** をクリックします。

## VRでマルチプレイチャットを開く

インフォパネル上部のon-lineリストを操作します。

- **ゲームルール行**：**Yell**（全員に送信）。
- **自分のチーム行**：**Whisper**（チーム内に送信）。他チームの行を宛先にする機能ではありません。

文字を入力して **Enter** で送信し、閉じます。空欄Enter、または **Close** は下書きを送らずキャンセルします。英字・記号、Shift、Backspace、左右カーソルに対応し、上限はASCII 191文字です。日本語IMEではありません。入力カーソルは点滅します。

送受信した発言はリストの上に、右が尖ったチーム色の名前背景と縁取り付き白文字で表示します。10秒保持し、1秒でフェードアウトします。新しい発言は最下段に追加し、古い発言を押し上げます。原作の通知音も維持します。

## VRでの両手入力

| 操作 | 物理コントローラーの入力 |
| --- | --- |
| 右ポインター先のキーを押す | 右トリガーまたはA |
| 左ポインター先のキーを押す | 左トリガーまたはX |
| いずれかのポインターがキーボード上にあるときにBackspace | Y |
| いずれかのポインターがキーボード上にあるときにEnter | B |

左の入力用レイはキーボードと交差したときだけ表示します。キー入力はユニット選択・グループ循環・ダイヤルメニューへ重複して渡しません。ボタンを離すまでキーボード側で保持します。キーボード外では通常操作を継続できます。チャット入力中は **Paused Game** と **Mission Objectives** をグレーアウトします。

ゲーム用の操作を入れ替えても、キーボードは上記の物理側の割り当てを維持します。

## 表示位置

起動画面の **キーボード** セクションでVRチャット用の配置を設定します。

- **空間固定**：初期ON。閉じるまで開いた位置・向きをゲーム空間に保持します。
- 固定OFFでは視線に追従します。**追従スムージング**は回転への追従を調整し、位置・奥行は即時追従です。
- 左右・上下・距離・スムージングは既定値との差を表示します。**中央の0がデフォルト**で、距離0やスムージングなしという意味ではありません。
- 基準は左右0 cm、上下−40 cm、距離175 cm、スムージング493 msです。スムージング表示は基準から−493～+493 msです。

値はハンドルに追従して表示します。次回VR起動時に反映されます。原作画面のキーボード配置を変える設定ではありません。
