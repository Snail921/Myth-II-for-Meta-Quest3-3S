# キーボードとマルチプレイチャット

[English](KEYBOARD.md) | **日本語** · [操作方法](CONTROLS.ja.md)

## 原作メニュー・ロビー・入力欄

原作メニュー、または入力欄を持つウィンドウで **BまたはYを1秒長押し**すると表示します。入力先の欄を選んでから入力してください。

## VRでマルチプレイチャットを開く

インフォパネル上部のon-lineリストを操作します。

- **ゲームルール行**：**Yell**（全員に送信）。
- **自分のチーム行**：**Whisper**（チーム内に送信）。他チームの行を宛先にする機能ではありません。

文字を入力して **Enter** で送信し、閉じます。

送受信した発言はリストの上に表示されます。10秒表示されたのちフェードアウトします。

## VRでの両手入力

| 操作 | 物理コントローラーの入力 |
| --- | --- |
| 右ポインター先のキーを押す | 右トリガーまたはA |
| 左ポインター先のキーを押す | 左トリガーまたはX |
| いずれかのポインターがキーボード上にあるときにBackspace | Y |
| いずれかのポインターがキーボード上にあるときにEnter | B |

左の入力用レイはキーボードと交差したときだけ表示されます。チャット入力中は **Paused Game** と **Mission Objectives** はグレーアウトされ利用できません。

ゲーム用の操作を入れ替えても、キーボード操作は影響されません。

## 表示位置

起動画面の **キーボード** セクションでVRチャット用の配置を設定します。

- **空間固定**：初期ON。閉じるまで開いた位置・向きをゲーム空間に保持します。
- 固定OFFでは視線に追従します。**追従スムージング**は回転への追従を調整できます。
