# ノーマルマップ集の使い方

[English](NORMAL_LIBRARY.md) | **日本語**

[ノーマルマップ集をダウンロード](https://github.com/Snail921/Myth-II-for-Meta-Quest3-3S/releases/download/v0.3.2-beta/MythIIVR-NormalMaps-0.3.2-beta.zip)

206コレクション分のノーマルパックです。全素材・全アニメーションを目視確認したものではありません。原作画像や編集用プロジェクトは含みません。

1. **0.3.2-beta以降のAPKとManager**をインストールします。APKは上書き更新し、初回セットアップはやり直さないでください。
2. ノーマルマップZIPを展開します。
3. Questの原作ゲームを終了し、USB接続します。
4. **Plugin Manager.cmd**を開き、「ノーマルマップフォルダ」に展開先の **NormalPacks** フォルダを指定します。
5. **「ノーマルマップをQuestへ転送」**を押します。同名パックは差し替えられ、旧版はQuestに残りません。
6. Questで **Myth II for Meta Quest 3 / 3S** を開き、強化影または強化ライティングをONにしてレベルを開始します。

元画像の指定、復元ツールの実行、ノーマルの再生成は不要です。画像の内容が一致するものだけに自動適用されます。異なるHD素材には対応するパックが必要です。

既存の旧形式パックも読み込めます。自作パックの変換方法は[材質エディタの説明](MATERIALS.ja.md)を参照してください。0.3.1-beta以前のAPKは新形式に対応していません。
