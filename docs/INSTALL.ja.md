# 導入手順

このプレリリースのAPK、PCツール、PBR材質パックを一緒に使用してください。材質ZIPを展開し、84個の .mvrnm が直接入っているフォルダをPlugin Managerで選択してQuestへ転送します。初回導入ではリリースにリンクした共通ランタイムも必要です。


[English](INSTALL.md) | **日本語** · [トップへ](../README.ja.md)


## 1. 必要なものを用意する

- Quest 3 / 3Sと、データ通信できるUSBケーブル
- Windows PC
- 自分のMyth II CD ISOとWindows用1.8.5アップデーター
- [Release](https://github.com/Snail921/Myth-II-for-Meta-Quest3-3S/releases/tag/v0.5.0-pbr-like.1)から入手するManager、APK、初回ランタイム

Myth II 1.8.5パッチ、高精細マップテクスチャ・ハイレゾスプライト（Twice Born Edition）、The Fallen Levelsなどのプラグインは、[Project Magma](https://projectmagma.net/)から入手できます。

VR用データの作成、転送に以下のソフトが必要になります。下記をPCにインストールしてください。

| ソフト | 用途 |
| --- | --- |
| [Python 3.11](https://www.python.org/downloads/windows/) | Managerを動かす。インストール時に「Add python.exe to PATH」をON |
| [7-Zip](https://www.7-zip.org/) | ISO・アップデーターを展開する |
| [Android Platform Tools](https://developer.android.com/tools/releases/platform-tools) | Questへ接続する。ZIPを展開しておく |

ManagerのZIPを展開します。そのフォルダでターミナルを開き、一度だけ次を実行します。

```powershell
python -m pip install -r requirements-manager.txt
```

その後、**Plugin Manager.cmd** をダブルクリックします。右上で日本語／Englishを切り替えられます。

ランタイムZIPも展開しておきます。中の **runtime-seed.tar** を手順3で指定します。

## 2. PCで原作データを変換する

上部の「作業・保存先」に、空き容量のあるフォルダを指定します。最低8 GiBに加え、HDアドオンや変換・転送用の余裕が必要です。

「セットアップ」タブの「原作セットアップ」で次を指定します。

| 項目 | 選ぶもの |
| --- | --- |
| ISOファイル | ISO化したMyth IIのCD |
| 1.8.5アップデーター | Windows用アップデーターEXE |
| 7-Zip | 通常は `C:\Program Files\7-Zip\7z.exe` |
| スカイボックス（任意） | スカイボックスZIPを展開した中の `Skyboxes` フォルダ |
| ロゴ画像／CD画像（任意） | Manager付属の `Assets/Logo.png` と `Assets/CD_Face.png`。それぞれ個別に指定 |

高精細画像を使う場合は「任意のHDアドオンを追加」で、別途入手したアーカイブ本体を選びます。Project MagmaのTwice Born Edithionを利用する場合、ダウンロードしたzipファイルを解凍し、その中にあるMagma - HD Megapack 1of2とMagma - HD Megapack 2of2の二つを指定してください。

**「原作を展開・全レベルを変換」** を押し、完了を待ちます。完了すると「セットアップ結果」に出力先が入ります。このフォルダは消さずに保管してください。

## 3. Questへ転送する

1. Questの開発者モードを有効にし、PCへUSB接続します。ヘッドセット内の「USBデバッグを許可」を承認します。
2. 対応APKをサイドロードツールでインストールします。ADBを使う場合は `adb install APKのパス` を実行します。
3. Questのアプリライブラリを開き、一覧のフィルターで **「提供元不明」** を選び、**「Myth II for Meta Quest 3 / 3S」** をクリックして一度開きます。ファイルへのアクセス許可が表示されたら許可します。まだ原作ゲームは起動しません。
4. Managerの「ADB」に、Platform Tools内の **adb.exe** を指定します。「接続確認」を押し、接続したQuestを選びます。
5. 「セットアップ結果」に手順2の出力先、「ランタイムデータ」に対応する **runtime-seed.tar** を指定します。
6. **「セットアップデータをQuestに転送」** を押します。USBを接続したまま、完了表示まで待ちます。

既存のゲームデータがある場合、初回セットアップは上書きしません。追加プラグインは下記の手順で配置します。

## 4. 起動して遊ぶ

1. Questを装着し、アプリライブラリを開きます。
2. 一覧のフィルターで **「提供元不明」** を選びます。
3. **「Myth II for Meta Quest 3 / 3S」** を右コントローラーで指し、右トリガーでクリックします。アプリの起動画面が開きます。
4. 起動画面の **「Initial setup / 初回データ展開」** を押し、完了を待ちます。この操作は初回だけ必要です。
5. 同じ起動画面で **「Myth II を起動」** を押します。
6. 原作メニューが表示されたら **New Game** を選び、Willow Creekを開始します。
7. 戦場がVR表示に切り替わればセットアップは成功しています。以後はPCを外して遊べます。

次回からは「提供元不明」→ **「Myth II for Meta Quest 3 / 3S」** → **「Myth II を起動」** の順に選びます。

最初は次の操作を試してください。（デフォルトの操作設定）

| 操作 | 入力 |
| --- | --- |
| 指し示す | 右コントローラーのポインター |
| 味方を選ぶ | 味方を指して左トリガー |
| 移動させる | 選択後、地面を指して左トリガー |
| 敵を攻撃する | 選択後、敵を指して左トリガー |
| 視点を移動する | 左スティック |
| 命令メニュー／隊形メニュー | A／X |
| 登録済みグループを切り替える | 初期設定ではYで前、Bで次 |

## 5. プラグインを追加する

原作が遊べる状態になった後、Manager上部のタブでプラグイン・素材モードに切り替えます。

1. 「原作フォルダ」に、セットアップ結果の中の **Game** フォルダを指定します。
2. 「プラグインファイル」に、展開済みのアーカイブ本体を指定します。例：`Chimera Single-player`、`Magma - The Fallen Levels v2`。
3. **① レベルを検査 → ② 全レベルを変換** の順に押します。
4. Questの原作ゲームを終了し、USB接続して **③ Questへ配置** を押します。
5. 完了後、原作メニューで追加したレベルを選びます。初回データ展開のやり直しは不要です。

すでに変換済みなら「変換済み bundle」にそのフォルダを指定し、③だけで転送できます。**The Fallen LevelsのTFL GameplayはOFF**にしてください。

## うまくいかないとき

| 症状 | 確認すること |
| --- | --- |
| Questが見つからない | USBケーブル、開発者モード、ヘッドセット内のUSBデバッグ許可 |
| 原作が稼働中と表示される | 原作ゲームを終了してから転送する |
| ファイルが対応していないと表示される | 対応する1.8.5アップデーターと原作データか確認する。名前だけ変更しない |
| VRに切り替わらない | 原作プラグインと変換済みパックが同じ組み合わせか確認する |
| 高精細画像が変わらない | 起動画面の対応設定をONにし、レベルを読み直す |

[不具合を報告する](https://github.com/Snail921/Myth-II-for-Meta-Quest3-3S/issues)

## 標準・追加の対戦マップを変換する

Managerの原作フォルダを指定し、標準マップならプラグイン欄を空にします。追加マップなら対応するプラグインファイルを指定します。「① レベルを検査」で種類（シングル／対戦／両対応）と検査結果を確認し、「② 全レベルを変換」「③ Questへ配置」の順に実行してください。配置時は原作ゲームを終了してください。

原作パックの更新はLevelPacksのみを対象とし、Game内の本体・セーブ・設定を置き換えません。標準データはシングル27面・対戦20面を検出します。未完成・対応ゲームモードなし・不足素材などの検査は維持します。「対応可能」は素材変換の検査結果で、全対戦ルールの実機動作確認を意味しません。対戦相手と同じゲーム／プラグイン構成を使用してください。

## 0.5.0のManagerと既存環境の更新

Managerは「セットアップ」と「プラグイン・素材」のタブで切り替えます。ログは共通で、仕切りをドラッグして広げられます。Manager・Sprite Editor・Quest起動画面の初期言語は英語です。保存済みの日本語設定は維持します。

新規セットアップでは原作のシングル・マルチ用マップを一緒に変換します。「任意のHDアドオンを追加」の下に「原作を展開・全レベルを変換」、その下に「セットアップ結果」と「セットアップデータをQuestに転送」があります。セットアップ結果はPCで変換した出力フォルダで、後日の転送にも使います。

旧版から更新する場合はAPKを上書きし、ランタイムの初回展開は繰り返さないでください。ペン／消しゴムの原作画像は新しいManagerがSharedAssetsへ抽出します。旧セットアップの画像が不足している場合、新しいManagerで別フォルダへ原作を変換し、原作を終了した状態で、その出力のSharedAssetsだけを下記の方法で転送してください。既存のGameやセーブを上書きする必要はありません。

出力パスを実際の場所へ置き換えてください。転送後にアプリを起動し直します。

    adb push "C:/path/to/new-setup/SharedAssets" /sdcard/Android/data/org.mythvr.standalone/files/
