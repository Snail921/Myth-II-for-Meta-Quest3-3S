# 操作方法

[English](CONTROLS.md) | **日本語** · [README](../README.ja.md) · [導入手順](INSTALL.ja.md)

**0.2.0-betaの初期設定**での操作です。右コントローラーでポインターを向け、戦場での選択や命令は**左トリガー**で確定します。「グリップ」は側面の握りボタンで、人差し指のトリガーとは別です。

## ユニットの選択と命令

| 操作 | 入力 |
| --- | --- |
| 味方を選択 | ポインターを合わせて左トリガーをクリック |
| 複数選択 | 左トリガーを押したまま範囲をドラッグ |
| 選択に追加 | 右トリガーを押しながら選択 |
| 同じ種類のユニットを選択 | 味方を左トリガーでダブルクリック |
| 移動 | ユニット選択後、地面を左トリガーでクリック |
| 攻撃 | ユニット選択後、敵を左トリガーでクリック |
| 特殊能力 | 左グリップ。利用できる能力はユニットによって異なります |
| 地面を指定して攻撃 | 右グリップを押しながら、地面を左トリガーでクリック |
| 命令メニュー | Aを押したまま項目の方向へコントローラーを動かし、Aを離す |
| 隊形メニュー | ユニット選択中にXを押したまま項目を選び、Xを離す |

### 移動せずに向きだけ変える

味方にポインターを合わせて左トリガーを**約0.35秒長押し**します。方向ガイドが出たら向かせたい方向を示し、トリガーを離します。未選択のユニットは先に選択されます。すでに選択中のユニットから始めた場合は選択を維持し、各ユニットがその場で向きを変えます。

### グループの登録と呼び出し

| 操作 | 入力 |
| --- | --- |
| 選択中のユニットを登録 | 右トリガー＋Xを押したまま登録枠を選び、Xを離す |
| メニューからグループを選択 | 右グリップ＋Xを押したまま枠を選び、Xを離す |
| 前／次のグループ | Y／B |
| 選択解除 | ジェスチャー有効時、左右どちらかのグループ操作ジェスチャー |

選択解除や手動選択を挟んだ場合、**最初のY／Bで最後のグループを呼び戻します**。次の操作から循環します。空のグループは飛ばします。

ジェスチャーは片方のコントローラーをもう片方へ近づけ、手前で止める動作です。実際にぶつける必要はありません。繰り返す前にいったん離してください。

起動画面の操作設定で、従来のジェスチャー循環モードへ切り替えられます。初期設定はY／Bで循環、左右のジェスチャーで選択解除です。

## 視点とパネル

| 操作 | 入力 |
| --- | --- |
| 視点移動 | 左スティック |
| 回り込み／旋回 | 右スティック左右 |
| 視点の高さ | 右スティック上下 |
| その場で旋回 | 右グリップ＋右スティック左右 |
| 選択ユニットへ視点ジャンプ | 右グリップを押さずに左スティック押し込み |
| 選択ユニットを追従 | 右グリップを押さずに右スティック押し込み |
| 追従を解除 | 左スティックを横へ動かす |
| ミニマップ表示切替 | 左コントローラーのメニューボタン |
| 情報パネル表示切替 | 右トリガー＋左メニューボタン |
| ミニマップから移動 | マップ上の位置にポインターを合わせて左トリガー |

## ゲーム速度

- **減速：右グリップ＋左スティック押し込み**
- **増速：右グリップ＋右スティック押し込み**
- 変更後、ミニマップ右上に現在の速度が白文字で約5秒表示されます。

次の段階へ変更するには、スティックの押し込みを一度離してください。原作のF1／F2操作を送るため、マルチプレイ時の権限や速度の上限・下限は原作に従います。左グリップは特殊能力用です。

## Co-opでユニットを割譲・返納する

1. 渡すユニットを選択します。
2. **右グリップを押しながらY**を押します。
3. 渡せる相手が1人なら即座に割譲します。複数なら操作時の視線の正面に一覧が出ます。名前にポインターを合わせ、**左トリガー**で確定します。

返納も同じ操作です。一覧の表示中は戦場への選択・移動命令を受け付けません。割譲せず閉じる場合はYを押します。

## 原作メニューと描画設定

起動画面と原作メニューは右ポインターと右トリガーで操作します。原作のレベル選択を開くには、入力キーボードで「Shift保持」をONにし、保持中の案内が表示されている間に「New Game」をクリックします。

起動画面の設定はグループごとに開閉できます。描画設定では片目あたりの解像度（自動／1680 × 1760／1832 × 1920／1920 × 2048／2064 × 2208）、72／80／90／120 Hz、MSAA（OFF／2×）を選べます。未対応のリフレッシュレートは対応設定へ戻ります。設定値は目標値で、同じFPSを保証するものではありません。変更は次回のVR起動時に反映されます。
