# 操作方法

[English](CONTROLS.md) | **日本語** · [README](../README.ja.md) · [導入手順](INSTALL.ja.md)

**0.5.0-betaの初期設定**での操作です。初期設定では右コントローラーでポインターを向け、戦場での選択や命令は**左トリガー**で確定します。ダブルクリック時にポインターと同じ手のトリガーを利用すると、マップ上の遠くのユニットをポイントし続けることが困難に感じたため、初期設定ではトリガー操作とポインター操作を左右の手で分けています。起動画面で変更可能なので、お好みに合わせて調整してください。「グリップ」は側面の握りボタンで、人差し指のトリガーとは別です。

## ユニットの選択と命令

| 操作 | 入力 |
| --- | --- |
| 味方を選択 | ポインターを合わせて左トリガーをクリック |
| 複数選択 | 左トリガーを押したまま範囲をドラッグ |
| 選択に追加 | 右トリガーを押しながら選択 |
| 同じ種類のユニットを選択 | 味方を左トリガーでダブルクリック |
| 移動 | ユニット選択後、地面を左トリガーでクリック |
| 攻撃 | ユニット選択後、敵を左トリガーでクリック |
| 特殊能力 | ユニット選択中に左グリップ。利用できる能力はユニットによって異なります |
| 地面を指定して攻撃 | ユニット選択中に右グリップを押しながら、地面を左トリガーでクリック |
| 命令メニュー | Aを押したまま項目の方向へコントローラーを動かし、Aを離す |
| 隊形メニュー | ユニット選択中にXを押したまま項目を選び、Xを離す |

### 移動せずに向きだけ変える

味方にポインターを合わせて左トリガーを**長押し**します。方向ガイドが出たら向かせたい方向を示し、トリガーを離します。

### グループの登録と呼び出し

| 操作 | 入力 |
| --- | --- |
| 選択中のユニットを登録 | 右トリガー＋Xを押したまま登録枠を選び、Xを離す |
| メニューからグループを選択 | 右グリップ＋Xを押したまま枠を選び、Xを離す |
| 前／次のグループ | Y／B |
| 選択解除 | 右グリップ＋B |
| ジェスチャーで選択解除 | ジェスチャー有効時、コントローラ同士を軽く打ち付けるように動かす（実際にぶつける必要はありません） |

起動画面の操作設定で、従来のジェスチャー循環モードへ切り替えられます。初期設定はY／Bで循環、左右のジェスチャーで選択解除です。

## 視点とパネル

| 操作 | 入力 |
| --- | --- |
| 視点移動 | 左スティック |
| 回り込み／旋回 | 右スティック左右 |
| 視点の高さ | 右スティック上下 |
| その場で旋回 | 右グリップ＋右スティック左右 |
| 選択ユニットへ視点ジャンプ | 右グリップを押さずに左スティック押し込み |
| 選択ユニットを追従 | 右グリップを押さずに右スティック押し込み |
| 追従を解除 | 左スティックを横へ動かす |
| ミニマップ・情報パネル表示切替 | 左コントローラーのメニューボタン |
| ミニマップから移動 | マップ上の位置にポインターを合わせて左トリガー |

## ゲーム速度

- **減速：右グリップ＋左スティック押し込み**
- **増速：右グリップ＋右スティック押し込み**
- 変更後、ミニマップ右上に現在の速度が白文字で約5秒表示されます。

## Co-opでユニットを割譲・返納する

1. 渡すユニットを選択します。
2. **右グリップを押しながらY**を押します。
3. 渡せる相手が1人なら即座に割譲します。複数なら操作時の視線の正面に一覧が出ます。名前にポインターを合わせ、**左トリガー**で確定します。

返納も同じ操作です。一覧の表示中は戦場への選択・移動命令を受け付けません。割譲せず閉じる場合はYを押します。

## 原作メニューと描画設定

起動画面と原作メニューは右ポインターと右トリガーで操作します。原作メニュー画面でYボタンを長押しすると、ソフトウェアキーボードを表示することが出来ます。SHIFTキーをクリックしてからNew Gameなどを選択することで、ロックを解除した状態でレベル選択を行えます。

起動画面の設定はグループごとに開閉できます。描画設定では片目あたりの解像度（自動／1680 × 1760／1832 × 1920／1920 × 2048／2064 × 2208）、72／80／90／120 Hz、MSAA（OFF／2×）を選べます。未対応のリフレッシュレートは対応設定へ戻ります。設定値は目標値で、FPSを保証するものではありません。変更は次回のVR起動時に反映されます。

[強化影・照明・LOD・FPS表示の設定](GRAPHICS.ja.md)

## 操作の入れ替え

起動画面の「操作」で、トリガー／グリップ／AとX／YとB／左右スティック（押し込みを含む）を個別に入れ替えられます。すべて初期OFFです。このガイドの表は入れ替え前の割り当てです。

「左右のコントローラーを入れ替える」はポインターとUIの追従側だけを交換します。ONでは左手がポインター、右手にUIが付き、インフォパネルのボタン・肖像・アイコン配置も左右を交換します。

## ミニマップへの書き込み

マルチプレイ時、インフォパネルのペンをクリックしてONにします。ポインターを地図に合わせ、選択用トリガー（初期は左）で描きます。カメラ移動の代わりにチーム色の線を描き、同じチームに共有します。

消しゴムをクリックすると、ミニマップ上の描きこみを消去できます。

**Allow Mini Map Rotation** は初期OFFです。ONではHMDの向きに追従しますが、ペンON中は一時的にミニマップの回転は止められます。
