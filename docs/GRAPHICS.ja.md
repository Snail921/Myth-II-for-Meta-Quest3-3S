# 描画設定とFPS

[English](GRAPHICS.md) | **日本語** · [ホーム](../README.ja.md)

Questのアプリライブラリ →「提供元不明」→ **Myth II for Meta Quest 3 / 3S** を開き、描画設定のグループを開きます。設定は次回のVR起動から反映されます。

| 設定 | 内容 |
| --- | --- |
| 解像度・リフレッシュレート・MSAA | 画質と負荷を調整。90Hzなどの指定は目標で、同じFPSを保証するものではありません |
| FPS表示 | ミニマップ左上に小表示。 |
| ハイレゾスプライトの高品質な輪郭（2パス） | 非推奨。OFFが標準の軽量描画。ONは輪郭を滑らかにしますが負荷が増えます |
| 強化された影 | ユニット・草木などのスプライトに影と簡易セルフシャドウを適用 |
| 影の最大減光量 | 影の濃さ。0%なら減光なし |
| 影サンプル数・強化影LOD開始距離 | サンプル数を増やすと滑らかになります。遠方の影はLODで簡略化 |
| 強化されたライティング | 炎・爆発・フェッチの雷などでスプライトを照らします |
| ライティングの影響度 | 光の効果の強さ |
| ビュー全体の最大光源数 | 視錐台判定後に採用する光源の上限。4～128。32程度で良いかも。 |
| オブジェクトごとの最大光源数 | 各スプライトに適用する上限。1～128、初期値8 |
| 照明LOD開始距離 | 初期値10。上限8なら遠方ほど8→4→2→1へ減少。0で無効 |

光源の中心が画面外でも、照射範囲が画面に届けば候補に残ります。左右の目と水面反射を考慮します。各スプライトには候補のうち届く光源だけを上限まで適用します。LODの光源数切替は段階式です。

ノーマルマップは自分で作成して追加することもできます。[スプライト材質の作成・転送](MATERIALS.ja.md)を参照してください。地面と建物などのメッシュは現在、強化影・照明の受光対象ではありません。

## 動作が重いとき

解像度を下げる、強化効果を切る、各描画要素を減らす、リフレクション品質を落とすなど、描画品質とFPSはトレードオフの関係です。
Bloom、強化影、強化ライティングなどを全て切った状態であれば、最高解像度でもほとんどのシーンで90fps出ると思います。

通常プレイでは診断用の固定視点や描画API待機詳細はOFFにしてください。描画性能はレベル・視点・設定で変わります。

## アトラス化・地形・水面

「テクスチャ・影」の**スプライトのアトラス化・まとめ描画（比較用）**をONにすると、FPSを向上できます。基本的にON推奨。全レベルで利用でき、コレクションの事前書き出しや変換作業は不要です。通常のページは2048×2048。カラーとノーマルは別テクスチャで、ノーマル画像は共有します。両方を合計した上限は768 MiBです。格納できない画像は従来方式で描画します。

アプリの外部filesフォルダの`atlas-high-water.tsv`に、レベル別のページ数・容量・フォールバックの最高記録を保存します。デバッグ、調整用のファイルなので普通に遊ぶ分には気にしなくてOKです。

**遠方の地面の詳細テクスチャを簡略化**は任意（初期OFF）。距離20～40で詳細模様を薄め、40以遠で省略します。地面の色と影は維持します。地形の背面カリングは自動です。水面の範囲計算を軽量化し、隠れた水面の反射を可視判定で自動省略します。GPUの結果をその場で待ちません。見えるようになってから反射が戻るまで、1フレーム以上遅れる場合があります。

## ポインターの色と太さ

**ミニマップ・メニュー**内の独立した設定です。保存され、次回VR開始時に反映します。

- **Auto Switch UI/Gizmo Color**（初期OFF）：レベル読み込み時に地面をサンプルし、明るい積雪風の地面や黄色い地面では、黄色の操作表示を指定色へ変更します。初期色は**RGB 245, 182, 66**。カラーピッカーで変更できます。敵や状態を示す色は維持します。
- **Thick Pointer UI**：**1.0～4.0倍**、0.1刻み、初期**1.0倍**。ポインターの線、地面のポインター・移動先サークル、向き指定の矢印、ホバー対象の矩形枠の太さを変更します。判定範囲、選択済みユニットの枠、体力バー、範囲選択の線は変更しません。数値はハンドルに追従します。

## 色補正とBloom（初期OFF）

色補正とBloomは独立して有効化できます。初期値は両方OFFです。OFF時はそれぞれの処理を迂回します。画質と速度は好みに合わせて選んでください。

| 設定 | 範囲・初期値 |
| --- | --- |
| 色補正の強度 | 0～100%、初期100%。空とUIを除き、100%で表示色を約1.28倍に補正 |
| Bloom処理解像度 | 縦横それぞれ1/32・1/16・1/8・1/6・1/4・1/2、初期1/8 |
| Bloomぼかし反復回数 | 1～4回、初期1回 |
| Bloom発光強度 | 0～200%、初期15% |

Bloomは空とUIを発光源から除外し、明るいハイライトを抽出してぼかします。炎や魔法の種類を直接判定する機能ではありません。強度を上げても描画負荷は増えません。解像度と回数は負荷に影響します。低解像度でも画面全体のコピー・合成コストは残ります。低解像度ほど発光が粗く、広く見える場合があります。かなり重たい処理なので、FPSを確保したい場合はOFF推奨ですが、描画解像度1680x1760であればそこそこFPS出てくれると思います。

描画解像度を最低にしてBloomを1/8にした軽いシーンで90fpsに達しました。全レベル・視点での保証ではありません。画質、演出、FPSのバランスを見ながら好みで調整してください。
