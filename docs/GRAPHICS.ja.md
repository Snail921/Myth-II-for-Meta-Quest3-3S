# 描画設定とFPS

[English](GRAPHICS.md) | **日本語** · [ホーム](../README.ja.md)

Questのアプリライブラリ →「提供元不明」→ **Myth II for Meta Quest 3 / 3S** を開き、描画設定のグループを開きます。設定は次回のVR起動から反映されます。

| 設定 | 内容 |
| --- | --- |
| 解像度・リフレッシュレート・MSAA | 画質と負荷を調整。90Hzなどの指定は目標で、同じFPSを保証するものではありません |
| FPS表示 | ミニマップ左上に小数点1桁で表示。0.1秒ごとに更新 |
| ハイレゾスプライトの高品質な輪郭（2パス） | OFFが標準の軽量描画。ONは輪郭を滑らかにしますが負荷が増えます |
| 強化された影 | ユニット・草木などのスプライトに影と簡易セルフシャドウを適用 |
| 影の最大減光量 | 影の濃さ。0%なら減光なし |
| 影サンプル数・強化影LOD開始距離 | サンプル数を増やすと滑らかになります。遠方の影はLODで簡略化 |
| 強化されたライティング | 炎・爆発・フェッチの雷などでスプライトを照らします |
| ライティングの影響度 | 光の効果の強さ |
| ビュー全体の最大光源数 | 視錐台判定後に採用する光源の上限。4～128 |
| オブジェクトごとの最大光源数 | 各スプライトに適用する上限。1～128、初期値8 |
| 照明LOD開始距離 | 初期値10。上限8なら遠方ほど8→4→2→1へ減少。0で無効 |

光源の中心が画面外でも、照射範囲が画面に届けば候補に残ります。左右の目と水面反射を考慮します。各スプライトには候補のうち届く光源だけを上限まで適用します。LODの光源数切替は段階式です。

ノーマルマップは別途作成して追加できます。[スプライト材質の作成・転送](MATERIALS.ja.md)を参照してください。地面と建物などのメッシュは現在、強化影・照明の受光対象ではありません。水面のスペキュラー用の影抑制は別処理です。

## 動作が重いとき

1. FPS表示をONにして確認します。
2. 高品質な輪郭をOFFにします。
3. 強化影・強化ライティングを一つずつOFFにして、影響を確認します。
4. 必要に応じて影サンプル数、光源数、解像度、MSAA、反射品質を下げます。

通常プレイでは診断用の固定視点や描画API待機詳細はOFFにしてください。描画性能はレベル・視点・設定で変わります。

## 光源数を調べる

強化ライティングと診断ログをONにして、火炎瓶などを1回だけ爆発させます。ログの `Lighting population` に候補数、区間内の最大数、発生・消滅数、通常画面／反射での採用数が記録されます。採用数は報告時点の値で、爆発が消えた後は0になります。発生・消滅数は取得できたゲーム状態の差分です。
