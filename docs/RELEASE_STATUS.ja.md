# リリース内容

[English](RELEASE_STATUS.md) | **日本語**

APK、初回ランタイム、Plugin Manager・ソース、スカイボックス、上流ソースを配布します。原作Myth IIと第三者のキャンペーン・HDプラグインは別途必要です。

新しく生成したランタイムを使い、Quest 3の独立した検証環境で初回展開、原作メニュー、Willow CreekのVR移行を確認しました。描画ログは約72 FPSで、ユニット操作の応答も確認しています。ベータ版であり、すべてのプラグインを検証したものではありません。

検証用コピーでは一度、原作パッチの配置漏れが発生しました。必須8ファイルを追加し、ハッシュを照合して解消しています。Managerの原作変換にはこれらが含まれます。

新しいビルド処理は、固定版のWinlator APKとプロジェクトのソースを使います。旧開発用APKや実機から書き出した環境は不要です。[ビルド手順](BUILD.ja.md)を参照してください。

初回ランタイムは0.1.0-betaから共通です。最新リリースにあるリンクから入手してください。既存環境のゲームデータ・セーブは保持します。Gameフォルダが存在する環境へ、原作セットアップをやり直す必要はありません。

0.5.0-betaの追加機能は[更新履歴](../CHANGELOG.ja.md)と[描画設定](GRAPHICS.ja.md)を参照してください。FPSは設定や場面で変わり、強化機能ONで90FPSを保証するものではありません。

## 0.5.0の確認

Questで色補正・Bloomをユーザー確認済み。Bloomの全解像度、MSAA有無、空の除外、状態復元、左右の残像防止のGPUテストを実行。Managerの変換・配置テストは7件通過。APKは既存署名と一致し、Java・描画・通信部分は実機確認版と同一です。Windowsヘルパーの再ビルドは実行セクション同一でタイムスタンプのみ変化。操作／キーボード／設定／導入の日英ガイドと同じソースを配布ZIPに含めます。

## Preview 3 — 0.5.0-pbr-like.3（2026-11-24）

今回の更新対象は`pbr-like`のみで、`main`は変更していません。反射準備・カリングの改善、フィルム再生クラッシュ修正、最大32 pxの反射スプライトLOD、診断用視点記録・固定を含みます。APKとManager／ソースZIPは同じソース改訂と日英ガイドに対応します。今回Manager自体の機能変更はありません。

公開APKは実機検証済みビルドのランタイムを保持し、公開用のバージョン情報を更新しています。署名証明書は従来と同じです。今回はランタイム全体の新規クリーンビルドではありません。既存データの再変換は不要で、Preview 2の材質パックとリンク先の初期ランタイム・スカイボックスを引き続き使用します。ダウンロード先はREADME、ハッシュはリリースのチェックサムを参照してください。元ゲームのファイルは含みません。


## Preview 4 — ユニファイド影とnoShadow（2026-11-28）

地形・建物・スプライトのユニファイド影、静的影キャッシュ、8Kまでの動的影解像度を追加。地面基本色の書き出し／読込、地形法線の補間、メッシュの共通シェーダー設定の共有を実装しました。元画像／影除去版の別プロジェクト、未編集HDより影除去アルベドを優先する経路、画像ごとのノーマル反転、終了時の復元保存エラー修正を含みます。独立したnoShadowパック（10コレクション／97画像）、APK、Manager／ソースZIPを公開。従来の通常／PBRパック、ランタイム、スカイボックスは継続利用できます。描画負荷および最適化不足によりFPSは50～60前後が目安で、保証値ではありません。[noShadowの導入と検証範囲](NOSHADOW.ja.md)。
