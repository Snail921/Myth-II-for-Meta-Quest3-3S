# リリース内容

[English](RELEASE_STATUS.md) | **日本語**

APK、初回ランタイム、Plugin Manager・ソース、スカイボックス、上流ソースを配布します。原作Myth IIと第三者のキャンペーン・HDプラグインは別途必要です。

新しく生成したランタイムを使い、Quest 3の独立した検証環境で初回展開、原作メニュー、Willow CreekのVR移行を確認しました。描画ログは約72 FPSで、ユニット操作の応答も確認しています。ベータ版であり、すべてのプラグインを検証したものではありません。

検証用コピーでは一度、原作パッチの配置漏れが発生しました。必須8ファイルを追加し、ハッシュを照合して解消しています。Managerの原作変換にはこれらが含まれます。

新しいビルド処理は、固定版のWinlator APKとプロジェクトのソースを使います。旧開発用APKや実機から書き出した環境は不要です。[ビルド手順](BUILD.ja.md)を参照してください。

APKと初回ランタイムは同じリリースのものを使ってください。既存環境のゲームデータ・セーブは保持します。Gameフォルダが存在する環境へ、原作セットアップをやり直す必要はありません。
