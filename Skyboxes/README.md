# Skyboxes / スカイボックス

Choose this folder in Plugin Manager during setup. To add images to an existing installation, copy them to:

`/sdcard/Android/data/org.mythvr.standalone/files/Skyboxes/`

Keep the filenames: each image matches a level name. Custom images should be 2:1 panoramas, at most 4096 × 2048, in PNG or JPEG format. Installing a skybox does not install the level itself.

初回セットアップ時にManagerでこのフォルダを指定します。既存の環境に追加する場合は、上記のフォルダへ画像をコピーしてください。

ファイル名はレベル名と対応するため、そのまま使います。自作画像は2:1・最大4096×2048のPNG/JPEGにします。スカイボックスを入れるだけではレベル自体は追加されません。
