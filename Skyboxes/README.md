# Skyboxes / スカイボックス

160 optional panoramas prepared for this VR project using image generation. These are artistic backgrounds, not extracted Myth landscape textures. They are provided for use with this project. No original scenario text is included in the sanitized metadata.

Use the entire folder as the optional Skyboxes input when preparing base data. For an existing installation, copy the images into:

`/sdcard/Android/data/org.mythvr.standalone/files/Skyboxes/`

Keep filenames: the loader matches the level display name, with `.png`, `.jpg` or `.jpeg`. Panoramas must be 2:1, at most 4096 × 2048. `.skybox.json` files retain conversion-time orientation information; they are not game scripts. Indoor levels may intentionally have no skybox. A skybox does not make an unsupported gameplay plugin compatible.

本プロジェクト用に画像生成で制作した任意の遠景です。原作地形画像の抽出物ではありません。本プロジェクトでの利用向けに提供します。公開用メタデータには原作シナリオ本文を含めません。

初回変換時はこのフォルダを指定してください。既存環境では上記 `Skyboxes` に画像を配置します。ファイル名はレベル表示名と一致させ、2:1・最大4096×2048にします。屋内レベルに空が無いのは意図した場合があります。画像の配置だけで未対応プラグインが動作可能になるわけではありません。
